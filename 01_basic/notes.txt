6th tab :-

==>Attributes

- Attributes are nothing but special feature of the tag
- Attributes are used to make some settings related to tags and provide some information to the browser.

Syn:
    <tag attribute =”val” attribute=”val”>
-Based on the purpose of the program we have to use the attributes.

Note: - Attribute must be type right side of the tag.
-After every attribute space is compulsory . 
-”val” or ‘val’ or val are all allowed formats for the value but “val” is recommended.
-Types of attributes 

1>Global attribute
2>Optional attribute
3>Specific attribute 
4>Event attribute

-Global,Optional,Specific attributes are general purpose.

-Event is dynamic attribute 

>General : Settings related and providing information to the browser.
>Dynamic : Calling javascript or invoking javascript. 

<html lang =”en”> optional attribute 

<link rel=”icon” href=”logo.png”> specific attribute

Align -> Global Attribute
